3. Description of the Software

SNote Retrieval is a Windows desktop export and retrieval utility designed to help users preserve and export supported Samsung Notes data that is available locally on their computer through the Samsung Notes Windows application.

The Software is intended solely as an export and retrieval utility. It does not provide functionality for creating, editing, organizing, managing, or synchronizing Samsung Notes.

When supported Samsung Notes data is available, SNote Retrieval reads the required files locally and presents a preview of the content that it has identified as available for export.

SNote Retrieval is designed as a read-only exporter. It does not modify, delete, overwrite, or otherwise alter the original Samsung Notes files that it reads.

The Software can create a ZIP file containing supported content identified as available for export, organized into regular folders and Markdown (.md) files.

The exported Markdown files contain plain-text content extracted by the Software. Content that the Software does not support for export is not included in the exported files.

The Software does not guarantee that every Samsung Note or every element of a note can be detected or exported.
